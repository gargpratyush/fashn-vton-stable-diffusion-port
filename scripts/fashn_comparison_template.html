Read this first

Generated images are not error maps. Every normal image below is explicitly labeled OUTPUT. Black, noisy, neon-edged maps are amplified pixel differences, not failed image generations. They are hidden in a separate diagnostic panel by default.

Scope: these are precision/runtime variants of the same FASHN model, not separate trained models. The current study completed 18 full image runs and 18 fresh-process forward probes. Historical runs are shown separately, not pooled into current averages. This report does not imply Android, ARM64 or GPU acceptance.

No quantized policy passed the strict floating trajectory agreement gates. PSNR is not a perceptual try-on score, and human acceptance has not been recorded. Smaller localized garment errors can be important even when global scores are high.

2. Numerical difference, latency & measured memory

One seed-42 run per case/policy. Sampling seconds include modulation preparation and trajectory recording. Process wall includes native startup/shutdown. These are prepared-input measurements: preprocessing, HTTP and model downloads are excluded.

Current-study two-case summary

Arithmetic means across cardigan and bottoms, not repeated-run uncertainty estimates. Memory here is the mean of each run's process peak, not simultaneous memory consumption.

Metric definitions and interpreting dB

RMSE: root mean squared channel error on the unresized 576x768 crop, using RGB values 0..255. MAE: mean absolute channel error. PSNR: 20 log10(255/RMSE), larger is closer. Exact matches have infinite PSNR, displayed as "Exact", not zero dB. A 6.02 dB reduction means approximately twice the RMSE.

Error variance: population variance of signed channel errors, not latency variance. Pixels >10: percentage whose maximum absolute RGB channel error exceeds 10. Worst 64x64: highest mean squared error on a 32-pixel-stride scan including the right/bottom boundaries; not an exhaustive pixel-stride search and not a garment segmentation metric.

Background and unchanged person pixels can dominate global scores. PSNR does not evaluate garment identity, fit, realism, texture preservation or whether either output is a good try-on.

3. Where the memory goes

All current runs use ready GGUF files with zero runtime weight conversions and no source mmap. About 996 MiB of modulation/conditioning weights are retired before denoising. Activations and protected F32 parameters remain: 4-bit weight storage does not mean a 4x process-memory reduction.

GiB = 2^30 bytes; MiB = 2^20 bytes. Working set and private commit overlap: never add them. Active assigned weights are sampled after modulation retirement; arena/cache values are observed high-water allocations. These logical allocation peaks may not coincide and do not account for every library-private allocation.

5. Repeatability, seed sensitivity & surgical restoration

Forward timing variability: three fresh processes per policy

Each process performs two fixed-state conditional t=0 forwards: first and warm. These timings are not full-generation latency predictions. SD is sample standard deviation; CV is SD/mean.

Seed 43: held-out descriptive comparison

Only BF16 and Q5_K were run at seed 43. These compare with each other at the same seed, not against seed-42 Q8. Two seeds do not establish population quality or robustness.

Q5_K with four matrices restored to original F32

The prior Q8-sensitive matrices at single_blocks 12, 11, 8 and 14 (linear1.weight) were restored. They were a hypothesis, not a new exhaustive Q5_K sensitivity ranking.

Important: aggregate error improves in both cases, but the cardigan's matched worst region becomes slightly worse. An improvement in a global average is not an unconditional visual improvement.

6. Scope, provenance & downloadable data

Host: Windows x64 CPU, AMD EPYC 7763 exposure, 16 inference threads, 2 load threads, no compute GPU. Current native protocol: 576x864 canvas, 20 steps, CFG 1.5, shift 1.5, skip last CFG step, seed 42 unless labeled, F32 flash attention, strict fused GELU, bounded modulation cache, ready weights, mmap off, one model process at a time. BF16 describes selected weight storage with F32 operands; quantized matrices execute directly.

Floating gates remain relative L2 <= 0.001 at every recorded image and guided velocity, initial-noise max error <= 1e-6, schedule max error <= 1e-7. Pixel-table reference changes do not change trajectory gate provenance. Seed-43 BF16's self-control is not an independent oracle. Quantized public inference remains disabled.

The report verifies the current run artifact hashes and recomputes cropped PNG metrics directly. Historical provenance is identified separately. It does not rerun inference or establish human approval. The interrupted final repeat was archived and rerun; incomplete work is not counted in timing statistics.
